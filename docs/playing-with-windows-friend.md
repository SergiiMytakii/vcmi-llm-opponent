# Windows-клиент для Mac-хоста с ChatGPT

Выбран отдельный Windows x64-клиент на том же upstream commit, что и
Mac-хост: `6a1ca68e00f540087f35579c62ffaf037f5be269` из `engine/version.json`.
На Windows используется неизменённый официальный клиент; ExternalAI и Codex
работают на Mac. Релизный клиент 1.7.x для этой партии не подходит.

## Готовый комплект

Локальный архив: `.build/windows-peer-6a1ca68/VCMI-Windows-friend-6a1ca68.zip`.
Передать другу весь архив. Пошаговая инструкция внутри — `README.txt`.
Он распаковывает архив в новую папку, запускает `Start.cmd`, импортирует
свои ресурсы Heroes III, согласует игровые моды с хостом и входит в комнату
как человек. Python, Codex и авторизация ChatGPT ему не нужны.
В архиве также есть исходники официальной сборки и лицензия VCMI.

`Start.cmd` задаёт переменную только для своих процессов. Комплектный
`engine/config/dirs.json` направляет пользовательские данные, конфигурацию,
сохранения, кеш и журналы в `profile` внутри распакованного комплекта.
Запуск exe напрямую обходит это назначение профиля.

На Mac запускать нашу сборку с контроллером через существующий
[изолированный запуск](playing.md) в режиме `human`, создать сетевую игру на карте с минимум
тремя слотами и назначить два человеческих слота и один ExternalAI.
Режим `human` задаёт `ai.adventureEnemyAI` и `ai.adventureAlliedAI` как
`ExternalAI`; поэтому для первой проверки оставить ровно один компьютерный слот.
Вместо двухслотовой Land Duel выбрать карту с тремя или более слотами.
AI должен оставаться под управлением Mac-хоста. Вход второго человека сам
по себе не доказывает, что AI получил правильное назначение: проверить
лог выбора `ExternalAI` и ответы контроллера на Mac.

## Приёмка на двух компьютерах

Готовность архива подтверждена проверкой commit внутри DLL, x64 PE,
контрольных сумм и неизменности файлов официального артефакта.
Это не подтверждение сетевой партии или запуска профиля на Windows.

Проверить на Mac и Windows:

1. Windows-лаунчер показывает отдельный каталог `profile` и нужную версию.
2. Оба человека входят в комнату; совпадают версии игровых модов.
3. ChatGPT получает ход на Mac; Windows не пытается создать ExternalAI.
4. Проходят несколько полных кругов ходов и бой.
5. Сохранение и загрузка возвращают оба человеческих слота и AI.
6. Журналы и сохранения Windows появляются только в комплектном `profile`;
   прежний профиль релизной установки не меняется.

При сбое сохранить Mac-логи контроллера, игровые логи обоих компьютеров
и сообщение об ошибке. До этой проверки совместимость всей партии остаётся
неподтверждённой; совпадающий commit устраняет известное различие develop/release.

# Проверенные знания для текущего набора карт и модов

Это начальный шаблон, а не готовая база правил Heroes III. Заполнять только
проверенными правилами текущей сборки и конкретными выводами из тестов.

Для каждой записи указать правило, источник и область применимости (версия игры,
моды, тип ситуации). Удалить запись, если новый прогон опровергает её.

Координаты скрытых объектов, полное содержимое тестовой карты и сведения зрителя
не включать. Разбор эпизода превращать в общее правило, а не ответ для одной карты.

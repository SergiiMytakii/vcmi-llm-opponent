VCMI: Windows-клиент для игры против ChatGPT на Mac-хосте

Windows 11 x64. Движок 1.8.0, commit:
6a1ca68e00f540087f35579c62ffaf037f5be269

1. Распакуй ВЕСЬ архив в новую доступную для записи папку,
   например C:\Games\VCMI-ChatGPT. Не распаковывай поверх релизной игры.
2. Запусти Start.cmd. Он открывает комплектный лаунчер с отдельным
   профилем profile рядом с ним. В мастере первого запуска проверь,
   что каталог пользовательских данных указывает на эту папку profile.
3. Укажи мастеру свою установленную Heroes III Complete / Shadow of Death
   для копирования ресурсов. Данные Heroes III в этот архив не включены.
   Если у тебя уже настроена VCMI: можно вручную СКОПИРОВАТЬ папки
   Data, Maps и Mp3 в profile. Не копируй старые config, cache или Saves.
4. Установи и включи те же игровые моды и их версии, что у Mac-хоста.
   Одного совпадения версии движка недостаточно. Не обновляй движок
   лаунчером: комплект зафиксирован на commit 6a1ca68.
5. Через этот лаунчер запусти игру. Подключись к комнате Mac-хоста
   и выбери человеческий слот. Другой человеческий слот занимает хост,
   а компьютерный игрок ChatGPT управляется на его Mac.

Codex, Python и вход в ChatGPT на Windows не нужны.
Для повторного запуска всегда используй Start.cmd. Запуск exe напрямую
без этого файла не задаёт путь к комплектному профилю profile.

После подключения проверьте несколько ходов, бой и сохранение/загрузку
той же сетевой партии. Архив содержит готовые официальные Windows-бинарники;
полная партия Mac + Windows с нашим AI ещё не проверена.
Если есть ошибка, сохрани сообщение и журналы profile\logs.
